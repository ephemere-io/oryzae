# plans — フロー

ここは**進行中の計画・作業票**の置き場。`docs/` 直下（ストック＝腐らない設計の正）とは
寿命が違うので、ディレクトリで分ける。開かなくてもパスで分かるように。

- 頭に「ステータス」と「最終更新」を書く（例: `## ステータス: Phase 1 未着手` / `最終更新: 2026-04-12`）
- 決まったことはストック側（該当のガイド）へ移し、ここには「これからやること」だけを残す
- 終わったら消す。初期設計として残す価値があれば `docs/archive/` へ
- Issue のチェックボックスで足りる作業票は Issue に。ここに置くのは、Issue に収まらない長さの計画
