# 用語集

画面に出る言葉の正。**同じものを 2 つの語で呼ばない**ための取り決め。

実機レビューで「『ジャーナル』『エントリー』『スタディジャーナル』のどれで通すのか」と
指摘されたのが発端（PR #570）。英字ラベルと日本語の本文がそれぞれ別の理屈で増えていて、
どこにも書いていなかった。

## 基本の対応

| 概念 | 日本語（本文） | 英字ラベル（3D の注釈） |
| --- | --- | --- |
| 1 件の記事 | エントリー | ENTRY / ENTRIES |
| 書く場所・1 冊の手帳 | 手帳 | ENTRIES（3D の注釈） |
| 手帳の集まり（棚） | 書庫 | ARCHIVE |
| 発酵の容れ物 | 瓶 | JAR |
| スニペットと写真を貼る板 | ボード | BOARD |
| ボードに貼る抜き書き | スニペット | （英字ラベルは使わない） |
| 部屋そのもの | 書斎 | （英字ラベルは使わない） |

### 「ジャーナル」と「エントリー」は別のもの

**ジャーナル（手帳）＝書く場所。エントリー＝その 1 件。** 包含関係なので、
本文でこの 2 語を混ぜない。日本語の本文で「ジャーナル」と書くのは**行為**を
指すときだけ（「ジャーナルを続けてください」）。物としての手帳は「手帳」と呼ぶ。

「スタディジャーナル」は使わない。

#### 3D の注釈だけは `ENTRIES` で通す

書斎の手帳に貼る注釈は、以前 `JOURNAL` だった。包含関係としては正しいが、
**押した先はエントリーの画面**で、ラベルだけが別の語で名乗っていた
（「ジャーナルではなくてエントリーという名前にしてほしい」— 実機レビュー）。

見た目の語だけを変えてある。内部の識別子（`LabelKind` の `journal`、i18n の
`label_journal`、`journal-new` / `journal-month` といった行き先）は**手帳のまま**で、
これは物としての手帳を指す語なので割れていない。

## 日本語は「エントリー」で通す

1 件を指すとき、日本語の本文は**エントリー**で統一する。書斎の側が「記録」を
使っていて割れていた（`この月の記録はありません` と `エントリーはまだありません` が
同じアプリの中に並んでいた）。

### 「記録」を残す場所

「記録」は**別の意味**で使っている箇所があり、そこは置き換えない。

| 文言 | 意味 |
| --- | --- |
| `連続記録` | 続いた日数（streak） |
| `L.A.B.による観察記録` | 発酵の観察ログ |
| `あなたの問いが生まれ、育ち、変化してきた記録` | 問いの変遷そのもの |

語を機械的に置換しないこと。**「エントリー」に置き換えてよいのは、1 件の記事を
指しているときだけ。**

## 英字ラベルを使う場所

英字の大文字ラベル（`JAR` / `ENTRIES` / `BOARD` / `ARCHIVE`）は、**書斎の 3D の物に
貼る注釈だけ**に使う。本文・ボタン・エラー文には使わない。書斎の外へ持ち出すと、
日本語の画面に英字が点在することになる。

## 追加するとき

`apps/client/src/i18n/messages/*.json` に語を足すときは、この表にある語を使う。
表に無い概念を増やすなら、まずここに 1 行足してから使う。
翻訳の運用そのものは `docs/i18n-guide.md`。
