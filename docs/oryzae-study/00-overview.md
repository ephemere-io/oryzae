# 00 — 画面・遷移・状態

## シナリオ

Oryzae を開くと 3D の書斎が最初に出る。書斎は entry / jar / board の実データを抽象化して映す
「状態の見える置き場」であり、それ自体が唯一のグローバルナビゲーションになる。

- **瓶（jar）** — 発酵 readiness に応じて中で言葉が泡立つ。完了すると泡が止み、封が浮かぶ。
  形は丸い硝子瓶にコルクの蓋（`21-3d-parameters.md`）。
- **手帳（entry）** — 書いた記録の数だけ厚くなる。月が替わると新しい手帳が積まれ、古い月は奥の棚へ。
- **壁掛けボード（board）** — 貼ったスニペットと写真が、ボード画面と同じ位置・回転・サイズで貼ってある。

## ナビゲーションの変更

### 左サイドバーの撤廃

`apps/client/src/features/pc/navigation/components/sidebar.tsx`（幅 80px 固定・blur・縦組み
ORYZAE ロックアップ・NAV_ITEMS 4つ・下端にアバター）は書斎ホームでは描画しない。
`app/(protected)/layout.tsx` の PC シェルから `<Sidebar />` と `marginLeft: SIDEBAR_WIDTH` を外し、
代わりに2つのフローティング要素を置く。

| 旧サイドバー | 書斎ホームでの行き先 |
| --- | --- |
| Jar | 瓶をクリック |
| Board | ボードをクリック |
| List（`/entries`） | 過去月の手帳をクリック → 月で絞った一覧オーバーレイ |
| Editor（`/entries/new`） | 当月の手帳をクリック |
| Account（アバター） | 左下フローティングのアバター（40px, blur, `/account`） |
| ロゴ | 左上フローティングのブランドマーク（40px, blur）。サブ画面では「BACK TO STUDY」を兼ねる |

未読バッジ（`#D4714E`）はサイドバーが消えるので、書斎では**封**が担う。数字バッジは出さない。

### エントリー一覧の扱い

一覧は独立した画面から**手帳を開いた後のオーバーレイ**に変わる。

- 手帳を開いた状態の**上中央**に `≡ ALL ENTRIES` / `≡ 2026.08 ENTRIES` のフローティングピル。
- 押すと紙のパネル（`#fdfbf7`, 1px `rgba(122,116,64,0.18)`, radius 12, 幅 720px）が
  手帳の上にかぶさる。行は日付・本文冒頭の抜粋・文字数・◦リンクした問い・PICKLED バッジ。
- 行をクリックするとオーバーレイが閉じ、その記録の本文が手帳の上に残る。

### 新規執筆の入口

役割を手帳で分ける。**当月の手帳＝新規執筆**、**過去月の手帳＝その月の一覧**。
FAB は置かない（書斎に常設ボタンを足すと、机の上の物で語る前提が崩れる）。

## 遷移

| 対象 | カメラ | その後 |
| --- | --- | --- |
| 瓶 | 左方向へ**パン**（突っ込まない）。1250ms, easeInOut | jar 画面へクロスフェード |
| 封 | 同じパン | jar 画面へ入り、L.A.B. の手紙を開いた状態で表示 |
| 当月の手帳 | 真上へ 950ms（同時に手帳の傾きを 0 へ）→ 表紙が開く 760ms → 見開き中心へ 620ms | entry 画面（新規執筆・0 CHARS・プレースホルダ） |
| 過去月の手帳 | 同上 | entry 画面 + その月に絞った一覧オーバーレイを開いた状態 |
| 棚の背表紙 | 背表紙が 0.22 持ち上がり、棚へ 1000ms パン | entry 画面 + その月の一覧（開くアニメーションは無し） |
| ボード（PC） | 正面へ 900ms | board 画面 |
| ボード（SP） | 正面へ 900ms → 120ms 待つ → `boardDist × 0.44` へ 860ms、並走で瓶が 620ms かけて消える | board 画面 |
| BACK TO STUDY | 画面を伏せて 550ms 後にホーム位置へ 900ms | 書斎（手帳の表紙・傾きをリセット） |

視点操作はマウス位置に応じた**軽いパララックス**のみ（x ±0.55 / y ±0.3, lerp 0.05）。
オービットもズームも与えない。ホームでは 1s 周期・振幅 0.05 の呼吸が乗る。

**遷移前に中身を決める。** 手帳の遷移では `mode`（新規執筆 / 閲読）と `scope`（対象月）を
**カメラが動く前**に確定させる。entry 層のフェードイン（0.8s）と本文の切替（0.4s）が重なると、
新規執筆に入る直前に前の記録が一瞬見えてしまう。戻るときも同様に、層が消えてから中身を戻す。

## 対象ラベルとホバー

初見の人に「押せる」ことだけを伝える最小の注釈。3D 座標に貼り付く HTML として、
毎フレーム `Vector3.project(camera)` で位置を更新する（透視スケールはかけない — 注釈は UI の側）。

| 対象 | ラベル | アンカー（world・PC） | SP |
| --- | --- | --- | --- |
| 瓶 | `JAR` | `(-4.2, -1.14, 2.7)` — 机の面、瓶の手前 | `jarZ + 1.45` |
| 手帳 | `ENTRIES` | `(3, -1.14, 4.12)` — 机の手前端 | `(deskX + 2.1, -1.14, deskZ + 1.1)` — 積みの右脇 |
| ボード | `BOARD` | `(0.9, -0.28, -4.05)` — 板の直下 | 板の直下（同じ式） |
| 棚 | `ARCHIVE` | PC では出さない | `(shelfX, shelfY + 2.1 × shelfScale, shelfZ)` |

SP では机の手前に余白が無く、PC と同じ「手前端」に置くと**手帳の表紙の上に文字が乗る**。
積みの右脇（空いている机の面）に逃がす。左脇はペンがいるので使えない。

表記は 9px Inter・大文字・トラッキング 0.24em・`#5C4F3F`、先頭に 3px の点（`#A8A381`）。
既定は不透明度 0.5、その対象をホバーすると 1.0（0.25s）。サブ画面と遷移中は消える。
点はクリック可能であることのほのかな手掛かりで、それ以上の装飾は足さない。

### SP の当たりと注釈

SP にはホバーが無い。**注釈そのものを押せるピルに変える**ことで、ホバーが担っていた
「押せる」提示と「中身の予告」を1つにまとめる。ツールチップは使わない（出す契機が無い）。

- 形: 角丸 999px、背景 `rgba(253,251,247,0.9)` + `blur(10px)`、枠 `rgba(122,116,64,0.22)`、
  影 `0 2px 12px rgba(140,133,126,0.14)`。**`min-height: 44px` を明示する**
  （パディングだけだと文字量で高さが変わり、下限を割る）。
- 中身: 点 + 機械ラベル + 状態語 + `›`。末尾の `›` とピル形状の2つで押せることを示す。
- 不透明度は常に 1.0（PC の 0.5 とホバーで濃くなる挙動は PC 限定）。
- 3D オブジェクト本体も引き続き的。タッチでは `pointermove` が先行しないことがあるので、
  `click` の中でもう一度レイキャストして拾い直す（`hovered` に頼らない）。

| ピル | 状態語 |
| --- | --- |
| `JAR` | `空` / `発酵中` / `もうすぐ`（readiness ≥ 0.9）/ `手紙` |
| `ENTRIES` | `n件`（当月） |
| `ARCHIVE` | `n冊` |
| `BOARD` | `n枚` |

readiness は SP でも数値にしない（「コピー」の規則に従う）。

**手帳のホバー**（PC のみ）では、その冊に何が入っているかを紙のツールチップで出す。
上段に `2026.09 — 当月`（過去月は `2026.08`）、下段に `11件の記録　09.01 – 09.02`。
日付範囲はその月の記録の最古・最新から作る（記録が無い月は件数のみ）。
棚の背表紙も同じツールチップを出す。

## 状態の見せ方

### 瓶（readiness を6箇所で）

| 要素 | 対応 |
| --- | --- |
| 泡の数 | `4 + readiness * 26`（完了時 4） |
| 泡の速度 | `0.45 + readiness * 1.7`（完了時 0＝静止） |
| 液面の高さ | `0.35 + readiness * 1.85`（瓶の内径に沿ったリング） |
| 漂う言葉の数 | `fermentation.words` を最大6件、mincho のスプライトで（下記の行間規則） |
| 輪郭の呼吸 | 4s 周期で不透明度 `1 - 0.35 * readiness * ...` |
| 上部のもや | `readiness > 0.2` で表示、不透明度 `0.25 + readiness * 0.4` |

瓶の中身は不透明な瓶体に隠れるため `depthTest: false` で輪郭の内側に重ねる（透視図の扱い）。
瓶体そのものは不透明のままなので、奥のボードは透けない。

**言葉の配置。** 液面までの高さ（`0.3` から `level - 0.14`）を**実際の語数**で割る。
行間はスプライトの高さ 0.24 の 1.7 倍を下回らせず、入らない語は出さない
（readiness が低ければ表示語数も減る＝発酵が浅い）。方位は黄金角 2.39996 rad ずつずらし、
上下の揺れは ±0.045（行間より十分小さく）。語数で割らずに固定の分母で並べると、
readiness が低いときに全部重なって灰色の滲みになる。
スプライトの幅は `measureText` で実測した文字幅から決める（全語同幅にしない）。

### 手帳

- 厚み = `0.1 + min(entryCount, 40) * 0.012`（1冊ごとに可変）。
- **紙の重なりを見せる。** 束は表紙より 0.09 小さく作り（表紙がわずかに出ることで箱に見えない）、
  小口・天・地の三方に薄い罫を入れる。本数は `clamp(round(厚み / 0.013), 7, 26)` で厚みに比例させ、
  1本ごとに端を 0.014 ずつ不揃いにし、濃度も 0.21 と 0.13 を交互にする。三方に入れるのは、
  クオータービューでどの角度からでも紙の断面が見えるようにするため。
- 机: 当月を一番上に、直近2ヶ月を下に積む。奥の棚: それ以前を背表紙で並べる（**直3ヶ月分**）。
- 3ヶ月を超えたら棚は詰めて表示する（間隔を縮める。スクロールも省略記号も出さない）。
- **背表紙には年月を刷る**（`2026.06`）。SP は棚を `rotation.x = -0.42` 前傾させ、
  書見台のように背文字を上向きに倒して読ませる。棚が「本が並んでいる場所」だと一目で分かり、
  背文字がそのまま行き先の予告になる。
- **記録が1件も無くても、当月の空の手帳を1冊だけ机に置く。** 机にペンだけが残ると
  新規執筆の入口が消える。`notebooks` が空配列のとき、コンポーネント側で
  `{ month: now.slice(0,7), entryCount: 0, current: true }` を補う（API は変えない）。

### 机

瓶と手帳が乗っている面は床ではなく**机の天板**。表現は最小限に留める — 天板の輪郭（`opacity 0.13`）、
手前の木端の厚み 0.16（`opacity 0.34`、ここだけ濃く引くと平面が板になる）、前脚2本、
木目を示唆する長い1本（`opacity 0.06`）。天板は `y = -1.2`、`x ±6.6`、`z -4.6..4.3`。
床の格子は `y = -2.9` に下げ、脚がそこまで伸びる。パラメータ `showDesk` / `showFloorGrid` で個別に切れる。

ペンは手帳の**右脇**に単体で寝かせる（机ローカル `(2.55, -0.15, -0.1)`、`rotation.x = π/2`,
`rotation.y = 0.3`）。本の輪郭に重なると軸だけが見えて何か分からなくなる。
胴（r0.055・長さ1.9）＋ペン先の円錐（0.34）＋バンド2本で、線画でもペンとして読める。

### ボード

- `cardType` / `x` / `y` / `rotation` / `width` / `height` / `zIndex` を実データ通りに使う。
- world 座標はカード群の bbox から比率を保って 8×5 の面に収める（`21-3d-parameters.md`）。
- 中身は罫線だけの抽象カード。snippet は罫線 n 本、photo は内枠1本 + 白（`#ffffff`）。

### 発酵完了の合図

`status === 'completed'` かつ手紙があるとき、瓶の口の上に**封**が浮かぶ（0.8s 周期の上下、
0.5s 周期の微小回転）。同時に泡が止まり静かになる。封をクリックすると jar 画面へ入り、
右から手紙のパネルがスライドして開く。テラコッタ（`#D4714E`）は使わない — 静けさで見せる。

## モバイル（SP）

SP でも書斎を出す。構図は**机と正対したクオータートップ**（仰角およそ 52°、fov 58）。
真上からでは壁のボードが表現できないため、机の面と壁の両方が入る角度に振っている。

縦画面は横に狭く縦に長い。横方向の視野は `aspect × 縦の視野` で決まり、390×844 では
縦の 46% しか横に使えないので、**物の並びを x（横）ではなく z（奥行き）に散らす**。
クオータートップでは奥行きの差が画面の上下差になるため、ボードが上・瓶が中・手帳が下に
自然に積まれる。

| | PC | SP |
| --- | --- | --- |
| fov | 45 | 58 |
| カメラ | `(0, 4, 12)` → `(0, 0, 0)` | `(0, 10.6, 7.8)` → `(0, -0.35, -0.7)` |
| 瓶 | `(-4.2, -1.2, 1)` | `(-1.15, -1.2, -0.2)` |
| 手帳（机の積み） | `(3, -1, 2)` | `(0.95, -1, 2.7)` |
| ボード | `(0.9, 2.5, -4)` 等倍 | `(0, 2.7, -4.2)` 0.68 倍 |
| 棚 | `(4.9, -1.2, -3.2)` 等倍 | `(2.0, -1.2, -2.6)` 0.72 倍 |
| 天板 | `x ±6.6`, `z -4.6..4.3` | `x ±3.4`, `z -4.7..4.0` |
| ペン | 積みの右脇 | 積みの左手前（右では画面外） |
| パララックス | あり | なし |
| 下端キャプション | 書斎 / STUDY / 状態 | 状態のみ（縦の余白が足りない） |

注視点を絵の中心より下（`y -0.35`）に置くことで全体が上に寄り、下端にキャプションの余白が残る。
**棚は SP では棚ごと1つの的**にして全月の一覧を開く（背表紙1本は指より細く、当たりを広げると
隣の月を拾ってしまう）。机の積み3冊・瓶・ボードは実測で 150px 以上の的になる。
月ごとの閲読は、開いた一覧の上に並ぶ**月チップ**（`ALL` / `2026.09` / …）で絞り込む。
これで背表紙を狙う必要が無くなる。チップは PC にも出す（同じ部品を使う）。

**SP のボード画面には右ペインを置かない。** 縦画面で 400px の側パネルを出すと板がほぼ潰れる。
カード枚数だけを隅に小さく浮かせ、**カードは指でつかんで動かせる**ようにする
（`pointerdown` → `setPointerCapture` → `transform: translate()`。つかんでいる間は影を深くし
`z-index` を最前面へ）。カードの重なりは指で解く前提。

行き先は現行の SP 画面（`features/sp/**`）のまま。WebGL 非対応・低スペック時のフォールバックは
`50-rollout.md`。

## コピー

書斎に出す文字は最小限。`書斎` / `STUDY` / 機械ラベルの状態表示、そして下記の対象ラベルのみ。

| 状態 | 機械ラベル | 和文 |
| --- | --- | --- |
| 記録なし | `NO ENTRIES YET` | まだ何もありません |
| 発酵中 | `FERMENTING` | 発酵中 |
| readiness ≥ 0.9 | `FERMENTING` | もうすぐ発酵します |
| 完了 | `LETTER ARRIVED` | 手紙が届いています |

readiness は数値では出さない（％表記はしない）。進み具合は瓶の見た目が語る。
