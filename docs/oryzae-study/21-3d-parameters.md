瓶のプロファイル。少数の制御点（`[radius, y]`）を Catmull-Rom で 5 分割ずつ標本化して
80 点前後の滑らかな母線にする:

```
[0,0] [0.35,0] [0.58,0.02] [0.78,0.09] [0.98,0.24] [1.16,0.48] [1.27,0.78]
[1.30,1.12] [1.29,1.45] [1.24,1.75] [1.15,2.02] [1.04,2.24] [0.95,2.44]
[0.90,2.62] [0.92,2.78] [0.97,2.88]
＋口縁: [1.0,2.90] [1.0,2.94] [0.86,2.94] [0,2.94]
```

丸い硝子瓶。胴の最大半径 1.30（y=1.12 付近）、首でわずかにくびれて 0.90（y=2.62）、
口縁で 1.0 に開く。全高 2.94、幅 2.60 — 口が胴より細いテーパーは維持している
（ゴミ箱と読み違えられないための形）。

**横線を立てないための設定が2つある。** ひとつは母線を細かく標本化すること、もうひとつは
`EdgesGeometry` のしきい値を既定の 15° ではなく **45°** にすること。滑らかな面では隣接面の
角度差が 45° を超えないので、底・胴・首に横線が1本も出ない（口縁とコルクの稜線だけが残る）。
緯線リングは置かない。縦の経線8本と、カメラに正対させたシルエット線だけで硝子の量感を出す。

コルク: `CylinderGeometry(0.83, 0.74, 0.38, 44)`、y=2.99（口縁 2.94 に少し沈む）、
塗りはブランドのクリーム `#F2EDE0`。側面に短い縦のかすれ6本（`opacity 0.18`）で木口を示す。
テラコッタは使わない。

液面・泡の湧く半径・もやの上限・封の浮遊高さはこの母線に依存するので、変えたら併せて見直す。

**側面の輪郭線**は EdgesGeometry では出ない（旋盤形状は側面に稜線を持たない）ので、
毎フレーム**真の輪郭**を解いて 1 本の `THREE.Line` に書き込む。経線は8本（`opacity 0.1`）、
緯線リングは置かない（横線を出さないため）。

母線の各標本 `(r, y)` と、その 2D 法線 `(n_r, n_y)`（前後の標本の差分から作る）について、
カメラの水平距離 `A`・方位 `α`・高さ `c_y`（瓶ローカル）を使うと、その高さの輪郭点は

```
cos(φ − α) = (n_r·r + n_y·(y − c_y)) / (n_r·A)
```

を満たす方位 `φ = α ± acos(...)` の2点。右枝を上から下へ、左枝を下から上へ繋いで一周させる。
右辺が ±1 を外れる高さ（＝そのリングに輪郭が無い）では枝が切れるので、**解が残る最下段の
リングを近側の弧 15 分割で閉じる**。

以前は母線とその鏡像をカメラ方位へ向ける近似（`rotation.y = atan2(-dx, -dz)`）だったが、
これは胴の膨らみの内側に入る**下半分の輪郭が消える**（見えている輪郭は母線平面上に無い）。
上下で線の濃さが違って見えたのはこれが原因。

線材は `depthTest: false` / `depthWrite: false` + `renderOrder 5`。面と同一深度に来ても
必ず手前に出るので、`scale` で外へ逃がす必要はない。頂点バッファは母線の点数 ×2 + 32 を
確保して `setDrawRange` で使う分だけ描く（毎フレームの再確保をしない）。

## ボードの座標変換

```
bbox = カード群の [x, x+width] / [y, y+height] の min/max
s    = min((8 - 1.1) / (maxX - minX), (5 - 0.9) / (maxY - minY))
pos  = ((x + width/2 - cx) * s,  -(y + height/2 - cy) * s,  0.13 + i * 0.006)
rot.z = -rotation * π / 180
```

DOM の y は下向き、3D の y は上向きなので符号が反転する。回転も同じ理由で反転。
`i` は `zIndex` 昇順の並び順（奥から手前へ 0.006 ずつ持ち上げる）。

## 遷移のタイミングとイージング

| 遷移 | 時間 | イージング |
| --- | --- | --- |
| 瓶へのパン | 1250ms | easeInOut cubic |
| 手帳の真上へ | 950ms | easeOut cubic（`1-(1-p)³`） |
| 手帳の傾き 0 へ | 950ms（同時並行） | easeOut cubic |
| 表紙が開く | 760ms（既定・可変） | easeInOut cubic |
| ページの追従 | 表紙の 0.24 倍遅れ + 1枚ごと 0.17 倍、各 0.82 倍の長さ | easeInOut cubic |
| 見開き中心へ寄る | 620ms | easeOut cubic |
| ボードへ（正対） | 900ms | easeOut cubic |
| ボードへ寄る（SP のみ・上の後） | 120ms 待ってから 860ms | easeInOut cubic |
| 瓶のフェードアウト（SP のみ・上と並走） | 620ms | ease |
| 棚へ | 1000ms（背表紙の持ち上げ 420ms） | easeInOut cubic |
| 書斎へ戻る | 550ms 待ってから 900ms | easeOut cubic |
| canvas のフェード | 600ms | ease |
| 画面レイヤーのフェード | 800ms | ease |

**SP のボードだけ2段構えにしている。** クオータートップから正対しただけでは、視線の手前に
瓶が残って主役を食う。そこで正対後に `boardDist × 0.44` まで寄せ、並走で瓶（瓶体・中身・
コルク・封・輪郭線）の不透明度を 0 まで落とす。瓶の素材は `initScene` の中で専用インスタンスに
clone してあり、`setJarOpacity(v)` が元の不透明度 × v を書く（0.02 以下で `visible = false`）。
書斎へ戻るときに 1 へ戻す。PC は俯瞰から正対するだけで瓶が視界に入らないので、この段は無い。

**カクつきの原因になった箇所**: tween 完了直後にアイドル時のカメラ揺らぎが復帰すると、
y が一段跳ぶ。揺らぎは `!busy && !view` のときだけ適用する（tween 中と遷移待ちの間は止める）。

## 遷移先のカメラ

遷移先はすべて配置表から導く（PC / SP で同じ式、距離だけ差し替え）。

| 対象 | 位置 | 注視点 | 距離 |
| --- | --- | --- | --- |
| 瓶 / 封 | `(jarX, jarY+3.2, jarZ + dist)` | `(jarX, jarY+1.5, jarZ)` | PC 5.6 / SP 5.9 |
| 手帳（真上） | `(deskX, topY + dist, deskZ + 0.06)` | `(deskX, topY, deskZ)` | PC 6.1 / SP 5.9 |
| 手帳（見開き） | `(deskX - 1.3, topY + dist - 1, deskZ + 0.04)` | `(deskX - 1.3, topY, deskZ)` | 同上 |
| ボード | `(boardX, boardY, boardZ + dist)` | `(boardX, boardY, boardZ)` | PC 4.5 / SP 11.3 |
| 棚 | `(shelfX - 0.7, shelfY+2.6, shelfZ+3.6)` | `(shelfX, shelfY+1, shelfZ)` | — |

`topY` = 机の y + その冊の上面。真上からの画角は `z` を注視点より 0.04–0.06 だけずらす
（完全な真上は up ベクトルと平行になり `lookAt` が破綻する）。
