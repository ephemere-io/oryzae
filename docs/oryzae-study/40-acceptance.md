# 40 — 受け入れ基準

## ナビゲーション

- [ ] フラグ ON・ログイン済みで `/` を開くと書斎が出る（`/entries/new` へ飛ばない）。
- [ ] 書斎に左サイドバーが無い。左上にブランドマーク、左下にアバターだけが浮いている。
- [ ] アバターから `/account` に行ける。マークはサブ画面で「BACK TO STUDY」として機能する。
- [ ] 瓶・当月の手帳・過去月の手帳・棚の背表紙・ボードの5つが全てクリックでき、ホバーでカーソルが変わる。
- [ ] jar / board / entry の各画面は現行 UI と同じ（今回の変更で見た目が変わっていない）。
- [ ] jar / board / entries を URL 直打ちしても従来通り開ける（書斎を経由しなくても壊れない）。
- [ ] ブラウザの戻るで書斎に戻る（履歴が壊れない）。

## 遷移

- [ ] 瓶は**左へパンして中央に来る**。突っ込むズームになっていない。
- [ ] 手帳は真上に着いてから開く。**着いた瞬間にカクッと跳ねない**。
- [ ] 開き終わってから画面が切り替わる（開く途中でフェードしない）。
- [ ] 当月の手帳 → 新規執筆（0 CHARS・プレースホルダ）。過去月 → その月の一覧が開いた状態。
- [x] ~~封をクリックすると jar 画面に入り、手紙が開いている。~~
      **封は書斎から外した**（`60-implementation-notes.md` §42）。手紙に会う場所は瓶の中だけ。
- [ ] `prefers-reduced-motion` でカメラ移動と開くアニメーションが飛び、クロスフェードだけになる。
- [ ] 当月の手帳を開いたとき、新規執筆が出る**直前に前の記録が一瞬見えない**（中身の切替がカメラ移動より先に済んでいる）。
- [ ] 書斎に戻るときも、entry 層が消えてから中身が戻る（戻り際の一瞬の切替が見えない）。

## 状態の反映

- [ ] readiness を変えると泡の数・速度・液面・輪郭の呼吸・もやが同時に変わる。
- [x] ~~漂う言葉が readiness の低い状態（starting / fermenting / almost）でも重ならず、1語ずつ読める。~~
      **瓶の言葉は書斎から外した**（`60-implementation-notes.md` §42）。
- [ ] 瓶が丸い硝子瓶に見え、底・胴・首に横線が出ていない（口縁とコルクの稜線だけ）。
- [ ] **瓶の輪郭が上から下まで同じ濃さで一周している**（下半分だけ薄い・消えている状態が無い）。PC と SP の両方で。
- [ ] カメラを動かしても輪郭が面から剥がれない・ちらつかない。
- [ ] コルクの蓋が口に収まって見え、色はクリーム（テラコッタではない）。
- [ ] 手帳が箱ではなく紙の束に見える（小口・天・地の三方に罫、厚い本ほど罫が多い）。
- [ ] `status: 'completed'` で泡が静まり、JAR のラベルが「手紙が届いている」に変わる
      （封は浮かべない。§42）。
- [ ] 記録を1件書いて戻ると当月の手帳が厚くなる。
- [ ] 月をまたぐと新しい手帳が一番上に積まれ、4ヶ月以上前は棚に移る（棚は直3ヶ月）。
- [ ] ボードのカードが board 画面と同じ位置・回転・サイズ・重なり順で貼ってある。
- [ ] 記録0件・問い0件・カード0枚（`empty` プリセット相当）で何も壊れず、机も壁も空で出る。
- [ ] **`empty` でも机にペンと空の手帳が1冊あり、それを押すと新規執筆に入れる**（ペンだけにならない）。
- [ ] 棚の背表紙に年月（`2026.06`）が読める。
- [ ] board だけ 500 が返っても書斎は出る（壁が空になるだけ）。

## ラベルとホバー

- [ ] 瓶・手帳・ボードの近くに `JAR` / `JOURNAL` / `BOARD` が出て、視点が動いても対象に貼り付いている。
- [ ] ラベルは既定で控えめ（不透明度 0.5）、その対象をホバーすると濃くなる。
- [ ] サブ画面と遷移中はラベルが消える。
- [ ] 手帳をホバーすると、月・件数・日付範囲のツールチップが出る（棚の背表紙も同じ）。
- [ ] 机の天板が板として読める（手前の木端と脚が見える）。`showDesk` を切ると消える。
- [ ] ペンが手帳に埋まらず、単体でペンとして読める。

## SP のタッチ提示

- [ ] SP で `JAR` / `JOURNAL` / `ARCHIVE` / `BOARD` の4つが**押せるピル**として常時見え、状態語（`発酵中` / `9件` / `3冊` / `10枚`）が添えられている。
- [ ] ピルの実測高さが **44px 以上**（`min-height` が効いている）。
- [ ] ピルを押すと対応する画面へ入る（3D の物本体を押したときと同じ行き先）。
- [ ] ピルが画面の端で切れない（狭い端末でも内側に押し戻される）。
- [ ] SP でどこにも数値の readiness（％）が出ていない。
- [ ] SP で棚が前傾し、背文字が読める。棚を押すと全月の一覧が開く。
- [ ] SP のボード画面に右ペインが無い。日付とカード枚数だけが隅にある。
- [ ] SP のボードでカードを指でドラッグでき、離した位置に留まる。つかんでいる間は最前面に来る。
- [ ] SP でボードへ入るとき、正対した後にさらに寄りながら手前の瓶が消える（瓶が主役を食わない）。
- [ ] 書斎へ戻ると瓶が元の濃さで戻っている（消えたままにならない）。

## 一覧オーバーレイ

- [ ] 手帳を開いた後、上中央のピルで開閉できる（SP は下端）。
- [ ] 一覧が開いている間はそのピルが消える（パネルの ✕ で閉じる）。
- [ ] 月チップ（`ALL` / `2026.09` / …）で月を切り替えられる。選択中のチップが塗られている。
- [ ] 記録が無い月を選ぶと「この月の記録はありません」と出る（空の行が並ばない）。
- [ ] SP でエディタの見出し行（`EDITOR` / `0 CHARS` / 日付）が折り返し、重ならない。
- [ ] 行に 日付 / 本文冒頭の抜粋 / 文字数 / ◦リンクした問い / PICKLED が出る。
- [ ] 過去月から開いたときはその月だけに絞られ、見出しが `2026.08 — 4 ENTRIES` になる。
- [ ] Esc で閉じる（`use-escape-key` を使う）。

## 品質

- [ ] 書斎を10回出入りしても `document.querySelectorAll('canvas').length === 1`（renderer が積まれない）。
- [ ] 書斎から離れると rAF が止まる（`cancelAnimationFrame` が呼ばれている）。
- [ ] `/jar` を直接開いたとき three.js がバンドルに含まれない（dynamic import が効いている）。
- [ ] SP で書斎がクオータートップ構図で出て、**瓶・ボード・手帳が3つとも画面に入り**タップできる。
- [ ] SP で瓶・ボード・机の手帳の当たりが 44px を大きく上回る（実測 150px 以上）。
- [ ] SP で棚は棚ごと1つの的になり、全月の一覧が開く（背表紙単位ではない）。
- [ ] SP でペンが画面外に出ない。下端のキャプションが手帳に重ならない。
- [ ] 390×844 でも 390×640 でも横方向に物が切れない。
- [ ] WebGL 非対応で静止フォールバックが出る（白画面にならない）。
- [ ] 発酵の取得が N+1 になっていない（`(protected)/layout.tsx` の1回取得を維持）。
